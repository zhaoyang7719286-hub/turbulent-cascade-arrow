# GitHub 上传与论文引用

建议仓库名：`turbulent-cascade-arrow`。项目已按英文科研仓库整理；作者、机构、邮箱和正式许可证没有擅自填写。

## 先在本机验证

解压后进入包含 README 的 `turbulent-cascade-arrow` 文件夹。按 README 用 Python 3.12 安装依赖，先运行输入校验、数值测试与图件重建。输出写入单独的 outputs 目录，不覆盖原始输入。全部九案例的 300 步动态重算由 `--all-cases` 显式启动，不会在通常的图件复算中自动运行。

仓库支持十张图的表级重建及给定 checkpoint 的动态演化。静态原始帧和旧通量模块仍需补齐，因此当前不宜写“所有原始场处理端到端复现”。缺口集中写在 README 与 UPSTREAM_GAPS；正文无需到处重复解释。

## 上传项目内容

在 GitHub 建一个空仓库，然后上传此项目文件夹里的内容。不要只上传整个 ZIP，也不要把原始交接压缩包、论文草稿、私人分析报告或访问 token 一起上传。

使用 Git 的示例命令如下。先在本机配置自己的 Git 身份；这里不代填作者姓名或邮箱。

```bash
git init
git branch -M main
git add .
git commit -m "Prepare numerical records and reproduction workflows"
git remote add origin https://github.com/OWNER/turbulent-cascade-arrow.git
git push -u origin main
```

OWNER 必须替换为真实账号或组织。上传前确认暂存内容包含 README、代码、数据、脚本、工作流与测试，不包含 outputs、本机虚拟环境或凭据。CI 工作流会运行离线复算，不请求 JHTDB 数据，也不上传论文。
